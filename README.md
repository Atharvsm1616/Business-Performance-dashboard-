# 📊 Business Performance Dashboard

## 📌 Project Overview
This project is a Business Performance Dashboard created to analyze and visualize sales data in a simple and easy way. 

The dashboard helps in understanding:
- Sales trends over time
- Performance across different regions
- Profit by product category
- Top-selling products
- Customer segment analysis

The main goal of this project is to convert raw data into meaningful insights using visualizations.

---

## 🎯 Objectives
- To track business sales performance
- To compare sales across regions
- To identify profitable categories
- To find top-performing products
- To understand customer segments

## 📊 Dashboard Features

### 1. Sales Trend
Shows how sales change over time.

### 2. Sales by Region
Compares performance across regions (Central, East, South, West).

### 3. Profit by Category
Displays profit for Furniture, Office Supplies, and Technology.

### 4. Top 10 Products
Shows highest selling products.

### 5. Segment Analysis
Analyzes Consumer, Corporate, and Home Office segments.

---

## 🔍 Key Insights
- Sales are increasing over time
- West region has highest sales
- Technology category is most profitable
- Few products generate most revenue
- Consumer segment contributes the most

---

## 📈 Conclusion
This dashboard helps in understanding business performance in a simple way. It supports better decision-making using data visualization.
